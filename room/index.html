Hi, I'm EngineGames-Development

      
I started as a Roblox and game developer. Over time I got into fullstack, cybersecurity, operating systems, AI and embedded systems. I have a passion for low-level programming, which started when I began building my own experimental operating system in Rust and C.

      
Instead of a list of interests, here is a room full of them. Almost every object in it does something real: a working 8-bit CPU, a crackme to reverse, packets built byte by byte, randomness harvested from a lava lamp.

    


    

      
What's inside the room

      

        
EG-8 CPU
An 8-bit CPU emulator with an assembler and disassembler. It drives LEDs, a robot arm, an LED matrix, an oscilloscope and a live RAM board.

        
SecureRustOS shell
A terminal on a CRT with a boot sequence, a GDT encoder, a memory map, make run, SQL and MongoDB queries and Linux easter eggs.

        
Security & reversing
A Ghidra-style crackme, a 5-flag CTF, packet capture with real IPv4 checksums, an antivirus scan, and nmap through a telescope.

        
Embedded & maker
An Arduino, a Raspberry Pi, a breadboard, a soldering station that heats up, a 3D printer and a quadcopter drone.

        
AI lab
A real neural network trains live on an easel and learns XOR with backpropagation. EngineBuddy floats around giving hints.

        
Game dev
Packet Catcher, a small original arcade game, plus a brick table where it all started, and 19 quests to complete.

        
Graphics
Toon shading with ink outlines, plus fragment shaders: a raymarched SDF, plasma, a Mandelbrot set, a CRT effect and lava-lamp metaballs.

        
Entropy & crypto
The lava lamp is an optical RNG (von Neumann debiasing + SHA-256) that feeds the password vault and the CPU.
